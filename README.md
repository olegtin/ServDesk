Разработал настольную информационную систему на C#, WPF, Entity Framework и Microsoft SQL Server для регистрации и обработки внутренних заявок сотрудников.
- реализовал авторизацию и ролевую модель: пользователь, IT-специалист, администратор;
- спроектировал базу данных заявок, пользователей, статусов, уведомлений, задач и истории изменений;
- реализовал автоматическое распределение заявок специалистам;
- реализовал автоматическое изменение статусов, историю жизненного цикла заявки и мягкое удаление;
- реализовал аналитику по заявкам и специалистам, фильтрацию по периодам и экспорт отчётов в Excel;
- добавил планирование задач, windows уведомления и управление уведомлениями.
